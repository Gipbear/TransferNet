## 4. 当前不应补做的事项

- 不重新运行已完成的四组分数组成消融、五组全量 QA、210 组参数扫描或 top-k 饱和性；
- 不将 100 条冒烟结果写入论文数值表；
- 不把骨干 TransferNet 原始答案指标当作路径方法指标；
