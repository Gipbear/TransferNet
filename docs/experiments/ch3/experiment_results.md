## 0.1 填表规则

1. 本地实验的每一行结果必须能够追溯到配置文件、结果目录或运行清单。
2. 引自论文的结果必须记录论文名称、表格编号或页码；不能只填写一个无法核对的数字。
3. 本地复现结果标记为“复现”，原论文报告结果标记为“论文”，二者不能混写。
4. 所有百分比统一使用 \(0\sim100\) 的百分数，保留两位小数；原论文只报告一位小数时保留
   原精度，不自行补零制造额外精度。
5. 不适用的单元格填写“—”，尚未获得的结果填写“待补”，实验失败填写“失败”，不能留空。
6. 每张表都填写实际样本数 \(N\)，避免把冒烟结果误写成全量结果。
7. `Hit@K`必须在表头写明具体的 \(K\)，不能只写“Hit”。
8. 所有最优值和次优值应在同一张表完成后统一加粗或下划线，填写过程中不要提前标记。
9. 不同方法使用不同知识图谱版本、问题子图、实体链接或LLM时，在“可比性说明”中如实记录。
10. 没有标准推理路径标注时，只使用“答案路径命中”“答案覆盖”和“关系多样性”等表述，
    不将路径尾实体正确直接表述为“路径完全正确”或“模型忠实”。
11. 如果参数使用测试集选择，必须标记为“诊断性结果”；只有验证集选参后一次性运行的测试集
    结果才能标记为“正式测试结果”。
12. 结论栏不仅记录是否提升，还要记录代价、例外数据集和可能原因。

- **充分支持**：核心指标一致提升，且无明显反例或口径问题；

- **不支持**：主要指标无提升或结论方向相反；

**表后分析：**

- 最优和次优方法：在监督式 KGQA 的外部结果中，ReaRev 为 76.4 H@1 / 70.9 F1；UniKGQA 增强变体为 77.2 / 72.2；RoG 的 85.7 / 70.8 是 WebQSP+CWQ 联合训练结果，不能与单数据集结果并列解释。
- 本章方法与最强可比方法的差值：暂不计算。TARRS 的本地 QA H@1 是固定 Llama 3.1 8B 零样本结果，而外部 H@1/F1 多为监督式答案预测，任务指标并不相同。
- 与需要 LLM 规划的方法相比的效果和成本：ToG、RoG、GNN-RAG 使用 LLM 规划、微调或额外路径调用；本章路径检索阶段不调用 LLM，但尚未完成跨实现、跨硬件的成本基准，因此不写速度优势。
- 子图或模型配置差异：外部方法分别使用 PRN / dense subgraph / max-hop subgraph、不同 Freebase 预处理和不同 LLM；本地使用固定 score cache 与 TransferNet 路径候选，必须单独报告。

**需要回答：**

- 加入关系相似度惩罚是否确实降低路径冗余？是。当前自适应项在同终点感知对照上使关系多样性从 63.20 提高到 71.10。

- 第二个创新点如何表述？可以保留“路径得分自适应的关系冗余抑制”，但必须同时报告 F1 权衡，并将覆盖和关系互补作为主要目标。
