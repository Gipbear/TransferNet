## 1. 章节标题与核心创新点

### 1.1 章节标题

> **第四章 基于路径证据引用监督的多跳问答大模型微调方法**

旧标题「基于事实信息增强的可解释多跳问答方法研究」表述过泛，无法与下述两个创新点一一
对应，不再使用。

### 1.2 两个核心创新点

1. **基于路径—答案对应关系的证据自动标注与抗位置偏置的指令数据构造方法。**
   利用检索路径尾实体与标准答案之间的匹配关系，自动将候选路径划分为支持路径与干扰路径，
   无需人工标注推理过程，也不依赖更强大语言模型蒸馏；在此基础上，通过训练期路径随机重排
   与引用编号同步重分配，以及可控比例的干扰路径注入，抑制模型对输入位置的依赖，迫使其
   学习基于事实内容的证据辨别能力。
   正文简称：**证据自动标注与抗偏置数据构造**。

2. **面向可追溯回答的证据引用式输出约束与支持路径优先的选择性微调方法。**
   设计以引用编号与答案实体为监督目标的输出格式，使模型在给出答案的同时输出其所依据的
   路径编号，使回答可被逐条回溯核验；并在训练中采用回复段选择性监督与支持路径优先保留的
   长度截断策略，保证每个监督答案在上下文中始终存在对应的事实依据，将优化目标聚焦为
   「给定候选路径后如何生成正确引用与答案」的条件生成任务。
   正文简称：**证据引用式输出约束与选择性微调**。

### 1.3 不单独包装为创新点的内容

与第三章 1.2 节采用同一纪律，以下内容在正文中作为必要技术处理或分析手段出现，不计入
创新点，也不在引言贡献列表中单列：

- QLoRA、LoRA、4-bit 量化与 LLaMA 3.1-8B Instruct 基座属于已有参数高效微调技术；
- 提示词掩码（仅对 Assistant 段计算损失）属于指令微调的标准做法，只有与「支持路径优先
  保留的截断策略」组合时才作为创新点二的组成部分陈述，不单独成点；
- 路径序列化格式（arrow/tuple/chain/nl）属于输入表示形式分析，不是方法创新；
- 检索束宽、训练轮数、训练集规模属于参数敏感性分析；
- 评测指标（Hit@1、Hits、Macro-F1、EM、Citation Accuracy、幻觉率）属于实验验证手段。

## 2. 本章要完成的总体论证

> 在第三章已获得显式知识路径的前提下，如何让大语言模型真正**依据**这些路径作答，而不是
> 依据路径在提示词中的出现位置作答，并使其答案可被逐条回溯到具体路径？

| 论证环节 | 需要回答的问题 | 本章的处理 | 主要证据 |
|---|---|---|---|
| 研究需求 | 为什么检索到路径还不够 | 基座模型零样本利用路径能力有限，且无法保证答案来自所给证据 | M2 零样本基线、第三章固定 LLM QA 结果 |
| 挑战一 | 训练数据的推理过程标注从哪来 | 用路径尾实体与答案的匹配关系自动划分支持/干扰路径 | 创新点一；方法 4.2.1 |
| 挑战二 | 为什么直接用检索顺序训练会失败 | 检索结果有序，模型会退化为「选第一条」而非辨别证据 | I1-a 关闭打乱消融 |
| 方法一 | 如何迫使模型学会辨别 | 训练期路径重排 + 引用编号重分配 + 可控干扰路径注入 | I1-a/b/c/d、I1-e |
| 挑战三 | 如何让答案可核验 | 以引用编号与答案实体共同作为监督目标 | 创新点二；方法 4.2.3 |
| 方法二 | 不同输出约束的代价与收益 | 对比仅答案、引用、结构化引用与思维链四种输出 | I2-a/b/c |
| 训练稳定性 | 超长上下文如何不破坏监督信号 | 截断时优先删除干扰路径、保留支持路径 | I2-d 触发率统计 |
| 整体效果 | 方法是否有实际价值 | 与零样本、无路径与现有方法对比，并检验鲁棒性 | M1、M3、M4、R1、R2 |

写作时保持五个位置一一对应：**引言贡献列表 → 本章标题 → 方法小节（4.2/4.3）→ 消融实验
（4.4.6/4.4.7）→ 本章小结**。任一位置出现第三个「创新点」都视为不一致。

## 3. 实验设计与创新点的对应关系

所有实验的上游输入统一为第三章 `transfernet_v2` 已发布产物；测试集为 WebQSP 1,581 条。
主实验使用随机种子 {17, 23, 29}，其余组固定 seed=17。

### 3.1 主线实验

| 编号 | 实验 | 关键设置 | 需训练 |
|---|---|---|---|
| M1 | 主实验 | `--format v2 --path_format chain --entity_repr name`，3 seeds | 3 |
| M2 | 零样本基座基线 | 同上下文，不加载 adapter | 0 |
| M3 | 无路径基线 | 复用 M1 adapter，推理不提供路径（`--no_paths`），3 seeds | 0 |
| M4 | 与现有方法对比 | 引用 RoG、GNN-RAG 等公开数值 | 0 |

M4 沿用第三章已完成的可比性核对口径：外部方法使用不同子图与系统配置时，只作方法路线与
历史结果背景，不与本章指标合并排名。

### 3.2 创新点一的直接证据（对应 4.4.7 数据构造策略消融）

| 编号 | 实验 | 关键设置 | 需训练 |
|---|---|---|---|
| I1-a | 关闭训练期路径打乱 | build `--no_shuffle` | 1 |
| I1-b | 干扰路径比例 ≤30% | build `--distractor_ratio 0.3` | 1 |
| I1-c | 干扰路径比例 ≤50% | build `--distractor_ratio 0.5` | 1 |
| I1-d | 显式注入路径检索得分 | build 与 eval 同时 `--show_score` | 1 |
| I1-e | 推理期路径顺序扰动 | eval `--shuffle_paths`，M1 模型与零样本基座各一组 | 0 |

I1-a 是创新点一的**反证**：关闭打乱后模型退化为位置选择器。I1-e 是**正证**：在推理期打乱
输入路径顺序，若 M1 模型指标基本不变而零样本基座明显下降，即说明抗位置偏置能力来自本章
的数据构造方法而非基座本身。两者必须成对报告。

I1-b/c 说明干扰路径的必要性：降低干扰比例会削弱辨别信号。注意基线（M1）为保留全部干扰
路径，因此这两组是**减弱**而非增强设置，结论方向应据实描述。

### 3.3 创新点二的直接证据（对应 4.4.6 输出格式对比）

| 编号 | 实验 | 关键设置 | 需训练 |
|---|---|---|---|
| I2-a | Answer（仅答案，无引用监督） | `--format v1` | 1 |
| I2-b | Cite-JSON（结构化引用） | `--format v3` | 1 |
| I2-c | CoT（显式关系归因） | `--format v4` | 1 |
| I2-d | 截断策略触发统计 | 从 build manifest 统计，非训练项 | 0 |

对照组为 M1（Cite）。本组**必须**报告 Citation Accuracy、幻觉率与输出格式合法率；若只报

I2-d 说明：当前 `kgqa.pfit.build` 未提供关闭「支持路径优先保留」的开关，无法构成标准消融。
因此该项改为统计上下文超长触发比例与触发时支持路径的保留率，作为设计合理性的说明性证据，
在正文中不表述为消融实验。

## 4. 与第五章的衔接

第五章 `llm_server` 当前固定加载 `models/webqsp/offline_ablation/offC_name_v2`，该 adapter
在旧检索配置下训练，与本章 M1 的新 adapter 不是同一模型。处理顺序已确定：

1. 先完成 M1，在同一 WebQSP 测试集上对比新旧 adapter 的 Hit@1、Macro-F1 与 Citation Accuracy；
2. 若差距在噪声范围内，第五章数值保持不变，并在第四、五章交界处说明所用 adapter 的训练配置；
3. 若差距显著，再单独评估第五章全量重跑的必要性。

在第 1 步完成前，不改动 `scripts/llm_server.sh` 的 `ADAPTER_PATH` 默认值。

## 5. 结论强度与写作边界

### 5.1 当前不能直接使用的结论

- 「本方法消除了大模型幻觉」——只能表述为在给定路径条件下幻觉率降至某个具体数值；
- 「模型输出的引用编号即模型真实的内部推理依据」——引用是被监督的输出行为，不等于因果
  归因，除非补充删除对应路径后答案随之改变的干预实验；
- 「在所有数据集上有效」——本章仅有 WebQSP 证据；
- 「优于所有现有方法」——外部方法子图与系统配置不同，沿用第三章的可比性口径；
- 「参数敏感性分析支持本章最优配置」——P1–P4 在旧检索配置下完成，且未使用独立验证集选参。

### 5.2 推荐结论强度

按最终数值可选择以下层级：

1. **最低可支持：** 路径监督微调使基座模型能够稳定利用第三章检索到的显式路径作答；
2. **数据构造消融支持后：** 训练期路径重排与干扰路径注入是模型获得证据辨别能力的关键，
   缺少该设计时模型退化为按输入位置选择；
3. **输出格式对比支持后：** 引用式输出约束在保持答案准确率的同时提供可回溯的证据编号，
   其代价与结构化程度相关；
4. **鲁棒性分析支持后：** 该能力在路径顺序扰动与噪声路径注入下保持稳定。
