# 第五章系统工作流架构与研究路线图（Architecture & Roadmap）

> **文档定位**：本文件记录第五章（基于知识图谱与大语言模型协同的复杂问答智能体系统）的系统整体架构、端到端控制流程、分支处理策略与后续攻关路线图。
> 记录时间：2026-10-07。

---

## 1. 整体定位与核心思想

第五章不再把问答视为“一次性输入、模型听天由命”的静态黑盒，而是构建**证据缺口驱动（Evidence Gap-Driven）的自适应知识图谱多跳推理工作流智能体**：

1. **复用前两章技术基石**：以第三章多样性路径检索（RSDPR）为证据来源，以第四章路径监督微调（PFIT）的**三强开源小模型共识池**为神经推理内核；
2. **两翼分流与差异化攻关**：
   - **已答分支（Answered）**：基本盘已锁定，针对**枚举型**（图谱拓扑展开）和**比较型**（符号属性重排）做定向精炼；
   - **拒答分支（Rejected）**：基于全量拒答模型近乎 99% 的拒答纯度，针对这批 0 分样本启动**应急救援（Rescue）**机制，下行误伤风险为零，主打安全增量召回。

## 3. 上游输入与推理内核约定

### 3.1 上游输入与子图
- **主题词（Topic MIDs）**：假定实体链接已完成，统一复用数据集自带的标准主题实体标注（如 WebQSP 与 RoG-CWQ 中的 `topics` 字段）。
- **知识图谱局部子图**：复用数据集构建时的既有成果（WebQSP 2-hop 子图，CWQ RoG/NSM 预抽取子图）。

### 3.2 路径检索（Ch3）
- 采用 **RSDPR（TransferNet + MMR 多样性 Beam Search）**：从局部子图中检索语义相关且结构多样的 Top-20 候选推理路径。

### 3.3 神经推理内核（Ch4 融合池）
- 采用 **三强开源小模型整组答案 Jaccard 共识池**：
  - `Llama3.1-8B`（Meta）
  - `Mistral-7B`（Mistral AI）
  - `Qwen3.5-4B`（阿里 Qwen）
- **训练规格**：CWQ 锁定**全量拒答微调版本**（27,631 条训练集，带 `--include_rejection`，1 epoch）。
- **实测表现**：全量测试集（N=3531）上 Hit@1 达 **59.53%**，EM 达 **51.20%**，拒答精确率（Precision）高达 **98.33%**，误拒仅 11 题，幻觉率低至 0.03%。

## 4. 核心分流机制与研究方向

### 4.1 方向 A：拒答样本的应急救援（Rejection Rescue）

- **立论逻辑（纯赚逻辑）**：
  三强共识判拒的样本，在当前阶段的得分为 0。系统对这批样本触发补充探索，**不存在将已答对题目改错的下行风险（误伤恒为 0）**；只要新工具能捞出正解，即为纯净的增量收益（Pure Gain）。
- **已有探索与手段**：
  1. **路径波束动态扩宽（Beam 20 → 30）**：
     - 在 CWQ 全量 3531 题上，检索波束扩宽使真实金答案覆盖数从 2599 $\to$ 2630（**净新增 31 题覆盖，0 题丢失**）；
     - 限制：必须单次输入或通过带拒答模型推理，严禁无门控地把后段分批（21–40）送入无判别力模型（此前已证实纯分批会产生盲目瞎猜）。
  2. **外部 QLever 开放图谱关系链反查**：
     - 针对 683 题原子图物理缺失任何答案节点的极端死局，通过训练集问题相似度预测 1–2 跳关系模板，调用 QLever SPARQL 在完整 Freebase 中查询；
     - 实测已成功捞回 **60 / 683 题（8.78%）的真实 gold 候选实体**；
  3. **待深入攻关问题**：
     - 关系链预测从粗粒度 TF-IDF 模板升级为 LLM 语义规划；
     - 候选实体拉回后，如何设计低误判的终态选答/核验机制。

---

### 4.2 方向 B：已答样本的题型自适应增强（Answer Refinement）

针对三强模型已经给出候选答案的样本，根据问题意图与结构进行专项精炼：

#### ① 枚举/集合题型（Set / List）
- **核心机制**：**获胜关系组全尾展开（`large_answer_expansion`）**。
- **实测战绩**：在 WebQSP（枚举题占 51%）上使 Micro-F1 从 49.86% 跃升至 **73.63%（+23.77pt）**，多答案子集提升 **+32.78pt**。
- **CWQ 适用性**：CWQ 题干常带复合伴随约束，无条件全量展开会引入伪答案（原生 −1.13pt）；必须接入 **B0 语义门控**（LLM 确认是否应枚举），实测门控后负收益完全抹平至 −0.06pt，副作用归零。

#### ② 比较/极值题型（Comparative / Superlative）
- **核心机制**：**QLever 符号属性查询与确定性比较重排（`CWQComparisonAnswerTool`）**。
- **痛点**：本地子图缺少 height, date, population 等 literal 属性谓词，模型单靠文本生成无法比较。
- **实测战绩**：
  - 在全量 3531 题属性重排中，**47 题救回，5 题误伤，净增 +42 题**（三模型共识底座上稳定净救回 +31 题）；
  - 属性重排与多跳拒答救援救回集合重叠度为 0，完全正交。

#### ③ 组合与合取题型（Composition & Conjunction）
- **现状与痛点**：
  - CWQ 全量 3531 题中，合取题（1,575 题）与组合题（1,546 题）合计占 88.4%；
  - 组合题（Composition）以多跳断链为主，已由多跳拒答门控成功攻克（净救回 239 题）；
  - 合取题（Conjunction）中有 81% 涉及 $\ge 2$ 个命名实体 Topic，需双主题检索求交；19% 涉及数值/时间等值过滤。
- **待深入攻关问题**：
  - 对 Conjunction 题型设计多主题并发双路检索与交集过滤（Intersection）；
  - 属性工具从“比大小（极值）”拓展到“数值/年份等值过滤”，攻关带值约束的合取题。
